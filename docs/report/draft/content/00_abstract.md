Intrusion detection systems built on deep learning are usually reported as accuracy figures on benchmark datasets, and are rarely shown acting on live traffic. This project builds and evaluates a complete intrusion detection and prevention system around a hybrid CNN-LSTM model that classifies windows of consecutive network flows, explains its decisions with SHAP (SHapley Additive exPlanations), and blocks attacking devices through the host firewall in real time. The model is evaluated on the CICIDS2017 benchmark with a chronological, leakage-controlled split, and on MU-IoT, real Internet-of-Things traffic recorded at Manipur University, India, with four whole recordings held out. A random forest trained and tested on identical examples is used as a fair baseline. The forest is better on CICIDS2017 (macro F1 0.780 against 0.586), whereas the CNN-LSTM is clearly better on MU-IoT (held-out macro F1 0.676 against 0.404), where single flow records are ambiguous and sequences resolve them. SHAP is used in the dashboard to explain every prediction and, offline, to separate three causes of the model's errors on unseen IoT recordings.

A per-class prevention policy derives each class's confidence threshold from its measured F1 score and locks unreliable classes to human review; on the CICIDS2017 test set it acts automatically on 96.6% of attack windows and on 0.33% of benign windows. A packet-to-flow extractor reproduces the CICFlowMeter-V3 features on 99.8% of flows from the original CICIDS2017 packet capture, so live traffic and Wireshark captures are analysed with the features the model was trained on. In a live run on a shared Wi-Fi network, a real port scan was detected about two seconds after its first probes and the scanning device was blocked automatically, while another user's falsely flagged device was refused by the safety checks. The limitations of a 2017-trained model on present-day traffic are measured and reported.

Keywords: intrusion detection, intrusion prevention, CNN-LSTM, deep learning, explainable AI, SHAP, CICIDS2017, MU-IoT, live packet capture.
